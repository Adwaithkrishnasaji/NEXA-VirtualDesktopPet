# NEXA AI  NEXA AI is an autonomous Windows desktop agent for Siri-style PC control. Built with Electron and multi-model AI, it automates OS tasks, controls apps, sets alarms, and manages local memory.  ## Features * **OS Automation:** PowerShell &amp; URI app control * **Smart Tasks:** Alarms &amp; reminders * **AI Engine:** Gemini &amp; Groq APIs
